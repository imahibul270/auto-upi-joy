# Auto Upi

UPI payment gateway (TanStack Start + Supabase).

## Hostinger / Node hosting (GitHub one-click)
- Build command: `npm run build:node`
- Start command: `npm run start`
- Node version: 22
- Env variables: see `.env.example`

Database setup: `database/GUIDE.md`. Full Hinglish guide: `database/AutoUpi-Hosting-Guide.pdf`.

## Local
```
npm install
npm run dev
```
